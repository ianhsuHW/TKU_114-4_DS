# 8/21 課堂實作與作業

## 單元名稱

List、Stack、Queue 與集合實作比較

## 課程定位

本日比較 `ArrayList`、`LinkedList`、`Deque` 與手寫 stack 的差異，並加強選擇資料結構的思維，而不是只記住 API。

## 學習目標

1. 使用 `List` interface 讓 implementation 可替換。
2. 比較 `ArrayList` 與 `LinkedList` 的操作特性。
3. 以 `Deque` 實作 stack 與 queue。
4. 自行實作固定容量 stack。
