# 8/20 課堂實作與作業

## 單元名稱

泛型與 Java Collections Framework

## 課程定位

本日以 generic class、generic method 與集合的抽象介面為主，讓同一組程式可以安全地處理不同型態資料，並理解 `Collection` 與 `Map` 的邏輯。

## 學習目標

1. 建立 generic class。
2. 建立 generic method。
3. 使用 `List`、`Set`、`Map` 做資料管理。
4. 理解 `Iterator` 與 loop 的差異。

- `GenericMethodDemo.java`
