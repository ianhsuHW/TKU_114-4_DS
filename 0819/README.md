# 8/19 課堂實作與作業

## 單元名稱

繼承、介面與多型

## 課程定位

本日將使用繼承與 `@Override` 建立共通抽象行為，讓不同類型的員工或付款方式都能依相同 interface/父類別進行處理。

## 學習目標

1. 使用 `extends` 建立繼承關係。
2. 以 `super()` 呼叫父類別建構子。
3. 使用 `@Override` 實作多型。
4. 依需求比較 inheritance 與 composition。
