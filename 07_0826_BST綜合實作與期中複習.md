## 核心概念

### 概念 1：Recursion 的進入、Base Case 與回傳

#### 概念說明

Recursive method 必須同時具備 base case 與會逐步接近 base case 的 recursive case。進入階段建立 stack frame，抵達 base case 後才依相反順序回傳。只看到呼叫順序，卻沒有追蹤回傳值，通常會在 tree recursion 中算錯 size、height 或 aggregate。

#### 實際應用

- Tree traversal 與 subtree 統計
- 目錄、組織結構與 expression tree
- 把大問題拆成相同形式的小問題

#### 資料變化

```text
factorial(4) -> factorial(3) -> factorial(2) -> factorial(1)；回傳 1 -> 2 -> 6 -> 24。
```

#### 設計判斷

先定義最小可直接回答的輸入，再確認每次 recursive call 都縮小問題。若輸入規模可能非常深，還要評估 stack overflow 與 iterative 寫法。

#### 範例程式

檔名：`RecursionTraceReview.java`

```java
public class RecursionTraceReview {
    static int factorial(int number, int depth) {
        String indent = "  ".repeat(depth);
        System.out.println(indent + "enter factorial(" + number + ")");

        if (number <= 1) {
            System.out.println(indent + "return 1");
            return 1;
        }

        int smallerResult = factorial(number - 1, depth + 1);
        int result = number * smallerResult;
        System.out.println(indent + "return " + number + " * "
                + smallerResult + " = " + result);
        return result;
    }

    public static void main(String[] args) {
        int answer = factorial(4, 0);
        System.out.println("answer=" + answer);
    }
}
```

執行結果：

```text
enter factorial(4)
  enter factorial(3)
    enter factorial(2)
      enter factorial(1)
      return 1
    return 2 * 1 = 2
  return 3 * 2 = 6
return 4 * 6 = 24
answer=24
```

#### 執行重點

縮排代表 call depth；進入順序與回傳順序相反。

### 概念 2：Traversal Order 的辨識與選擇

#### 概念說明

Preorder 在 children 之前處理 node，適合先建立或複製 parent；inorder 在左右 subtree 中間處理 node，對 BST 產生排序結果；postorder 在 children 之後處理 node，適合先完成或刪除 child。Traversal 的差異是處理 node 的時機，不是 left/right 的方向任意改變。

#### 實際應用

- Preorder 複製 tree structure
- Inorder 產生排序報表
- Postorder 計算目錄容量或刪除 subtree

#### 資料變化

```text
標準樹 root=50；preorder 先輸出 50，inorder 在 left subtree 後輸出 50，postorder 最後輸出 50。
```

#### 設計判斷

先問「parent 應在 child 前、中、後處理」，再選 traversal，不要背誦名稱後直接套用。

#### 範例程式

檔名：`TraversalOrderReview.java`

```java
import java.util.ArrayList;
import java.util.List;

class ReviewNode {
    int value;
    ReviewNode left;
    ReviewNode right;

    ReviewNode(int value) {
        this.value = value;
    }
}

class ReviewBst {
    private ReviewNode root;

    boolean add(int value) {
        if (root == null) {
            root = new ReviewNode(value);
            return true;
        }

        ReviewNode current = root;
        while (true) {
            if (value == current.value) return false;
            if (value < current.value) {
                if (current.left == null) {
                    current.left = new ReviewNode(value);
                    return true;
                }
                current = current.left;
            } else {
                if (current.right == null) {
                    current.right = new ReviewNode(value);
                    return true;
                }
                current = current.right;
            }
        }
    }

    boolean contains(int target) {
        ReviewNode current = root;
        while (current != null) {
            if (target == current.value) return true;
            current = target < current.value ? current.left : current.right;
        }
        return false;
    }

    List<Integer> searchPath(int target) {
        List<Integer> path = new ArrayList<>();
        ReviewNode current = root;
        while (current != null) {
            path.add(current.value);
            if (target == current.value) break;
            current = target < current.value ? current.left : current.right;
        }
        return path;
    }

    List<Integer> inorder() {
        List<Integer> result = new ArrayList<>();
        inorder(root, result);
        return result;
    }

    private void inorder(ReviewNode node, List<Integer> result) {
        if (node == null) return;
        inorder(node.left, result);
        result.add(node.value);
        inorder(node.right, result);
    }

    List<Integer> preorder() {
        List<Integer> result = new ArrayList<>();
        preorder(root, result);
        return result;
    }

    private void preorder(ReviewNode node, List<Integer> result) {
        if (node == null) return;
        result.add(node.value);
        preorder(node.left, result);
        preorder(node.right, result);
    }

    List<Integer> postorder() {
        List<Integer> result = new ArrayList<>();
        postorder(root, result);
        return result;
    }

    private void postorder(ReviewNode node, List<Integer> result) {
        if (node == null) return;
        postorder(node.left, result);
        postorder(node.right, result);
        result.add(node.value);
    }

    int size() {
        return size(root);
    }

    private int size(ReviewNode node) {
        if (node == null) return 0;
        return 1 + size(node.left) + size(node.right);
    }

    int height() {
        return height(root);
    }

    private int height(ReviewNode node) {
        if (node == null) return -1;
        return 1 + Math.max(height(node.left), height(node.right));
    }

    int leafCount() {
        return leafCount(root);
    }

    private int leafCount(ReviewNode node) {
        if (node == null) return 0;
        if (node.left == null && node.right == null) return 1;
        return leafCount(node.left) + leafCount(node.right);
    }

    String deleteCase(int target) {
        ReviewNode node = findNode(target);
        if (node == null) return "MISSING";
        if (node.left == null && node.right == null) return "LEAF";
        if (node.left == null || node.right == null) return "ONE_CHILD";
        return "TWO_CHILDREN";
    }

    private ReviewNode findNode(int target) {
        ReviewNode current = root;
        while (current != null) {
            if (target == current.value) return current;
            current = target < current.value ? current.left : current.right;
        }
        return null;
    }

    boolean remove(int target) {
        if (!contains(target)) return false;
        root = remove(root, target);
        return true;
    }

    private ReviewNode remove(ReviewNode node, int target) {
        if (target < node.value) {
            node.left = remove(node.left, target);
        } else if (target > node.value) {
            node.right = remove(node.right, target);
        } else {
            if (node.left == null) return node.right;
            if (node.right == null) return node.left;
            ReviewNode successor = minimumNode(node.right);
            node.value = successor.value;
            node.right = remove(node.right, successor.value);
        }
        return node;
    }

    private ReviewNode minimumNode(ReviewNode node) {
        while (node.left != null) node = node.left;
        return node;
    }

    List<Integer> range(int low, int high) {
        List<Integer> result = new ArrayList<>();
        if (low <= high) range(root, low, high, result);
        return result;
    }

    private void range(ReviewNode node, int low, int high,
                       List<Integer> result) {
        if (node == null) return;
        if (low < node.value) range(node.left, low, high, result);
        if (low <= node.value && node.value <= high) result.add(node.value);
        if (node.value < high) range(node.right, low, high, result);
    }

    boolean isValid() {
        return isValid(root, Long.MIN_VALUE, Long.MAX_VALUE);
    }

    private boolean isValid(ReviewNode node, long low, long high) {
        if (node == null) return true;
        if (node.value <= low || node.value >= high) return false;
        return isValid(node.left, low, node.value)
                && isValid(node.right, node.value, high);
    }

    void forceDeepViolationForTest() {
        if (root != null && root.left != null && root.left.right != null) {
            root.left.right.value = root.value + 5;
        }
    }
}

public class TraversalOrderReview {
    private static ReviewBst standardTree() {
        ReviewBst tree = new ReviewBst();
        for (int value : new int[]{50, 30, 70, 20, 40, 60, 80}) {
            tree.add(value);
        }
        return tree;
    }

    public static void main(String[] args) {
        ReviewBst tree = standardTree();
        System.out.println("preorder=" + tree.preorder());
        System.out.println("inorder=" + tree.inorder());
        System.out.println("postorder=" + tree.postorder());
    }
}
```

執行結果：

```text
preorder=[50, 30, 20, 40, 70, 60, 80]
inorder=[20, 30, 40, 50, 60, 70, 80]
postorder=[20, 40, 30, 60, 80, 70, 50]
```

#### 執行重點

三種 traversal 走過相同 node，只改變 node 被加入結果的時機。

### 概念 3：BST Invariant 與全域範圍驗證

#### 概念說明

BST invariant 要求每個 node 的整個 left subtree 都小於該 node，整個 right subtree 都大於該 node。只檢查直接 child 會漏掉深層 node，因此 validation 必須沿 recursion 傳遞 ancestor 建立的 low/high boundary。

#### 實際應用

- 檢查 insert/delete 後的資料結構
- 讀入外部 tree 資料後驗證
- 在測試中偵測深層 reference 錯接

#### 資料變化

```text
40 原本位於 30 的 right，範圍是 (30,50)；改成 55 後雖然仍大於 parent 30，卻違反 ancestor 50 的上限。
```

#### 設計判斷

Validation 檢查的是整體 invariant。使用 long boundary 可讓 Integer.MIN_VALUE 與 Integer.MAX_VALUE 仍是合法 key。

#### 範例程式

### 概念 4：Search Path、Insert Position 與 Duplicate

#### 概念說明

Search 與 insert 共用相同 decision path。Target 較小往 left、較大往 right；search 在相等時成功，insert 在遇到 null child 時建立 leaf。相等 key 的 policy 必須明確，本教材讓 add 回傳 false 且不改 tree。

#### 實際應用

- 依學號或商品編號建立動態索引
- 顯示搜尋比較路徑
- 防止唯一 key 重複

#### 資料變化

```text
搜尋 65：50 -> 70 -> 60 -> null；insert 65 使用同一路徑，最後接到 60.right。
```

#### 設計判斷

若只需 exact lookup，HashMap 通常更直接；若還需要排序與 range query，BST 才能同時支援這些操作。

#### 範例程式

檔名：`SearchInsertTraceReview.java`

```java
import java.util.ArrayList;
import java.util.List;

class ReviewNode {
    int value;
    ReviewNode left;
    ReviewNode right;

    ReviewNode(int value) {
        this.value = value;
    }
}

class ReviewBst {
    private ReviewNode root;

    boolean add(int value) {
        if (root == null) {
            root = new ReviewNode(value);
            return true;
        }

        ReviewNode current = root;
        while (true) {
            if (value == current.value) return false;
            if (value < current.value) {
                if (current.left == null) {
                    current.left = new ReviewNode(value);
                    return true;
                }
                current = current.left;
            } else {
                if (current.right == null) {
                    current.right = new ReviewNode(value);
                    return true;
                }
                current = current.right;
            }
        }
    }

    boolean contains(int target) {
        ReviewNode current = root;
        while (current != null) {
            if (target == current.value) return true;
            current = target < current.value ? current.left : current.right;
        }
        return false;
    }

    List<Integer> searchPath(int target) {
        List<Integer> path = new ArrayList<>();
        ReviewNode current = root;
        while (current != null) {
            path.add(current.value);
            if (target == current.value) break;
            current = target < current.value ? current.left : current.right;
        }
        return path;
    }

    List<Integer> inorder() {
        List<Integer> result = new ArrayList<>();
        inorder(root, result);
        return result;
    }

    private void inorder(ReviewNode node, List<Integer> result) {
        if (node == null) return;
        inorder(node.left, result);
        result.add(node.value);
        inorder(node.right, result);
    }

    List<Integer> preorder() {
        List<Integer> result = new ArrayList<>();
        preorder(root, result);
        return result;
    }

    private void preorder(ReviewNode node, List<Integer> result) {
        if (node == null) return;
        result.add(node.value);
        preorder(node.left, result);
        preorder(node.right, result);
    }

    List<Integer> postorder() {
        List<Integer> result = new ArrayList<>();
        postorder(root, result);
        return result;
    }

    private void postorder(ReviewNode node, List<Integer> result) {
        if (node == null) return;
        postorder(node.left, result);
        postorder(node.right, result);
        result.add(node.value);
    }

    int size() {
        return size(root);
    }

    private int size(ReviewNode node) {
        if (node == null) return 0;
        return 1 + size(node.left) + size(node.right);
    }

    int height() {
        return height(root);
    }

    private int height(ReviewNode node) {
        if (node == null) return -1;
        return 1 + Math.max(height(node.left), height(node.right));
    }

    int leafCount() {
        return leafCount(root);
    }

    private int leafCount(ReviewNode node) {
        if (node == null) return 0;
        if (node.left == null && node.right == null) return 1;
        return leafCount(node.left) + leafCount(node.right);
    }

    String deleteCase(int target) {
        ReviewNode node = findNode(target);
        if (node == null) return "MISSING";
        if (node.left == null && node.right == null) return "LEAF";
        if (node.left == null || node.right == null) return "ONE_CHILD";
        return "TWO_CHILDREN";
    }

    private ReviewNode findNode(int target) {
        ReviewNode current = root;
        while (current != null) {
            if (target == current.value) return current;
            current = target < current.value ? current.left : current.right;
        }
        return null;
    }

    boolean remove(int target) {
        if (!contains(target)) return false;
        root = remove(root, target);
        return true;
    }

    private ReviewNode remove(ReviewNode node, int target) {
        if (target < node.value) {
            node.left = remove(node.left, target);
        } else if (target > node.value) {
            node.right = remove(node.right, target);
        } else {
            if (node.left == null) return node.right;
            if (node.right == null) return node.left;
            ReviewNode successor = minimumNode(node.right);
            node.value = successor.value;
            node.right = remove(node.right, successor.value);
        }
        return node;
    }

    private ReviewNode minimumNode(ReviewNode node) {
        while (node.left != null) node = node.left;
        return node;
    }

    List<Integer> range(int low, int high) {
        List<Integer> result = new ArrayList<>();
        if (low <= high) range(root, low, high, result);
        return result;
    }

    private void range(ReviewNode node, int low, int high,
                       List<Integer> result) {
        if (node == null) return;
        if (low < node.value) range(node.left, low, high, result);
```

### 概念 5：Delete Case 分類與 Reference Replacement

#### 概念說明

Delete 必須先依 child 數分類。Leaf 回傳 null；one-child node 回傳唯一 child；two-child node 以 right subtree minimum 作 successor，複製資料後再刪除原 successor。Recursive result 要重新指定給 parent link，刪除 root 時也要指定回 root。

#### 實際應用

- 取消訂單或移除索引資料
- 維持搜尋結構可達性
- 處理 root 與內部 node 的替換

#### 資料變化

```text
先刪 20 是 LEAF；此時 30 只剩 right 40，刪 30 是 ONE_CHILD；50 仍有兩個 child，刪 50 是 TWO_CHILDREN。
```

#### 設計判斷

分類依據是刪除當下的 tree shape，前一個刪除操作可能改變後續 node 的 case。

#### 範例程式

檔名：`DeleteCaseClassifier.java`

```java
import java.util.ArrayList;
import java.util.List;

class ReviewNode {
    int value;
    ReviewNode left;
    ReviewNode right;

    ReviewNode(int value) {
        this.value = value;
    }
}

class ReviewBst {
    private ReviewNode root;

    boolean add(int value) {
        if (root == null) {
            root = new ReviewNode(value);
            return true;
        }

        ReviewNode current = root;
        while (true) {
            if (value == current.value) return false;
            if (value < current.value) {
                if (current.left == null) {
                    current.left = new ReviewNode(value);
                    return true;
                }
                current = current.left;
            } else {
                if (current.right == null) {
                    current.right = new ReviewNode(value);
                    return true;
                }
                current = current.right;
            }
        }
    }

    boolean contains(int target) {
        ReviewNode current = root;
        while (current != null) {
            if (target == current.value) return true;
            current = target < current.value ? current.left : current.right;
        }
        return false;
    }

    List<Integer> searchPath(int target) {
        List<Integer> path = new ArrayList<>();
        ReviewNode current = root;
        while (current != null) {
            path.add(current.value);
            if (target == current.value) break;
            current = target < current.value ? current.left : current.right;
        }
        return path;
    }

    List<Integer> inorder() {
        List<Integer> result = new ArrayList<>();
        inorder(root, result);
        return result;
    }

    private void inorder(ReviewNode node, List<Integer> result) {
        if (node == null) return;
        inorder(node.left, result);
        result.add(node.value);
        inorder(node.right, result);
    }

    List<Integer> preorder() {
        List<Integer> result = new ArrayList<>();
        preorder(root, result);
        return result;
    }

    private void preorder(ReviewNode node, List<Integer> result) {
        if (node == null) return;
        result.add(node.value);
        preorder(node.left, result);
        preorder(node.right, result);
    }

    List<Integer> postorder() {
        List<Integer> result = new ArrayList<>();
        postorder(root, result);
        return result;
    }

    private void postorder(ReviewNode node, List<Integer> result) {
        if (node == null) return;
        postorder(node.left, result);
        postorder(node.right, result);
        result.add(node.value);
    }

    int size() {
        return size(root);
    }

    private int size(ReviewNode node) {
        if (node == null) return 0;
        return 1 + size(node.left) + size(node.right);
    }

    int height() {
        return height(root);
    }

    private int height(ReviewNode node) {
        if (node == null) return -1;
        return 1 + Math.max(height(node.left), height(node.right));
    }

    int leafCount() {
        return leafCount(root);
    }

    private int leafCount(ReviewNode node) {
        if (node == null) return 0;
        if (node.left == null && node.right == null) return 1;
        return leafCount(node.left) + leafCount(node.right);
    }

    String deleteCase(int target) {
        ReviewNode node = findNode(target);
        if (node == null) return "MISSING";
        if (node.left == null && node.right == null) return "LEAF";
        if (node.left == null || node.right == null) return "ONE_CHILD";
        return "TWO_CHILDREN";

    private ReviewNode findNode(int target) {
        ReviewNode current = root;
        while (current != null) {
            if (target == current.value) return current;
            current = target < current.value ? current.left : current.right;
        }
        return null;
    }

    boolean remove(int target) {
        if (!contains(target)) return false;
        root = remove(root, target);
        return true;
    }

    private ReviewNode remove(ReviewNode node, int target) {
        if (target < node.value) {
            node.left = remove(node.left, target);
        } else if (target > node.value) {
            node.right = remove(node.right, target);
        } else {
            if (node.left == null) return node.right;
            if (node.right == null) return node.left;

            node.value = successor.value;
            node.right = remove(node.right, successor.value);

        return node;

    private ReviewNode minimumNode(ReviewNode node) {
        while (node.left != null) node = node.left;
        return node;

        List<Integer> result = new ArrayList<>();
        if (low <= high) range(root, low, high, result);
        return result;
    }

    private void range(ReviewNode node, int low, int high,
                       List<Integer> result) {
        if (node == null) return;

        if (low <= node.value && node.value <= high) result.add(node.value);
        if (node.value < high) range(node.right, low, high, result);

    boolean isValid() {
        return isValid(root, Long.MIN_VALUE, Long.MAX_VALUE);

    private boolean isValid(ReviewNode node, long low, long high) {
        if (node == null) return true;
        if (node.value <= low || node.value >= high) return false;

                && isValid(node.right, node.value, high);

            root.left.right.value = root.value + 5;
        }
    }
}
```

### 概念 6：Edge Case Test：Empty、Single Root 與 Duplicate

#### 概念說明

資料結構不能只測完整而平衡的 tree。Empty tree、single-node root、duplicate、missing target、連續刪除到 empty 都會碰到 root 或 null reference，是最容易暴露錯誤的案例。

#### 實際應用

- 建立 regression test
- 確認 public method 的回傳 contract


### 概念 7：Recursive Aggregate：Size、Height 與 Leaf Count

#### 概念說明

Tree aggregate 通常由左右 subtree 的答案組合而成。Size 使用加總；height 使用左右較大值；leaf count 只在 node 兩個 child 都是 null 時加一。三者看似相近，但 base case 與組合規則不同。

#### 實際應用

- 估算索引深度與搜尋風險
- 統計組織或目錄節點
- 檢查 tree shape 是否偏斜

#### 資料變化

```text
標準 7-node tree：size=7、height=2、leaf=4；升冪插入 5 個值形成 chain：height=4、leaf=1。
```

#### 設計判斷

Height 必須先固定定義。本教材採 empty=-1、leaf=0，edge count 等於 height。

### 概念 8：Path 與 Range Query 的剪枝

#### 概念說明

BST range query 不必無條件走訪所有 node。Current value 小於 low 時可略過 left subtree；大於 high 時可略過 right subtree。符合範圍時依 inorder 加入結果，即可直接得到升冪資料。

#### 實際應用

- 查詢價格區間、日期區間或成績區間
- 顯示 search comparison path
- 建立有序篩選報表

#### 資料變化

```text
查 [35,70]：略過 30 以下資料，依序收集 40、50、60、70；80 超過 high，不收集。
```

#### 設計判斷

本範例使用 inclusive boundary。當 low > high 時回傳 empty list，避免交換參數造成 caller 不知道實際查詢條件。

#### 範例程式

檔名：`BstPathRangeReview.java`

```java
import java.util.ArrayList;
import java.util.List;

class ReviewNode {
    int value;
    ReviewNode left;
    ReviewNode right;

    ReviewNode(int value) {
        this.value = value;
    }
}

class ReviewBst {
    private ReviewNode root;

    boolean add(int value) {
        if (root == null) {
            root = new ReviewNode(value);
            return true;
        }

        ReviewNode current = root;
        while (true) {
            if (value == current.value) return false;
            if (value < current.value) {
                if (current.left == null) {
                    current.left = new ReviewNode(value);
                    return true;
                }
                current = current.left;
            } else {
                if (current.right == null) {
                    current.right = new ReviewNode(value);
                    return true;
                }
                current = current.right;
            }
        }
    }

    boolean contains(int target) {
        ReviewNode current = root;
        while (current != null) {
            if (target == current.value) return true;
            current = target < current.value ? current.left : current.right;
        }
        return false;
    }

    List<Integer> searchPath(int target) {
        List<Integer> path = new ArrayList<>();
        ReviewNode current = root;
        while (current != null) {
            path.add(current.value);
            if (target == current.value) break;
            current = target < current.value ? current.left : current.right;
        }
        return path;
    }

    List<Integer> inorder() {
        List<Integer> result = new ArrayList<>();
        inorder(root, result);
        return result;
    }

    private void inorder(ReviewNode node, List<Integer> result) {
        if (node == null) return;
        inorder(node.left, result);
        result.add(node.value);
        inorder(node.right, result);
    }

    List<Integer> preorder() {
        List<Integer> result = new ArrayList<>();
        preorder(root, result);
        return result;
    }

    private void preorder(ReviewNode node, List<Integer> result) {
        if (node == null) return;
        result.add(node.value);
        preorder(node.left, result);
        preorder(node.right, result);
    }

    List<Integer> postorder() {
        List<Integer> result = new ArrayList<>();
        postorder(root, result);
        return result;
    }

    private void postorder(ReviewNode node, List<Integer> result) {
        if (node == null) return;
        postorder(node.left, result);
        postorder(node.right, result);
        result.add(node.value);
    }

    int size() {
        return size(root);
    }

    private int size(ReviewNode node) {
        if (node == null) return 0;
        return 1 + size(node.left) + size(node.right);
    }

    int height() {
        return height(root);
    }

    private int height(ReviewNode node) {
        if (node == null) return -1;
        return 1 + Math.max(height(node.left), height(node.right));
    }

    int leafCount() {
        return leafCount(root);
    }

    private int leafCount(ReviewNode node) {
        if (node == null) return 0;
        if (node.left == null && node.right == null) return 1;
        return leafCount(node.left) + leafCount(node.right);
    }

    String deleteCase(int target) {
        ReviewNode node = findNode(target);
        if (node == null) return "MISSING";
        if (node.left == null && node.right == null) return "LEAF";
        if (node.left == null || node.right == null) return "ONE_CHILD";
        return "TWO_CHILDREN";
    }

    private ReviewNode findNode(int target) {
        ReviewNode current = root;
        while (current != null) {
            if (target == current.value) return current;
            current = target < current.value ? current.left : current.right;
        }
        return null;
    }

    boolean remove(int target) {
        if (!contains(target)) return false;
        root = remove(root, target);
        return true;
    }

    private ReviewNode remove(ReviewNode node, int target) {
        if (target < node.value) {
            node.left = remove(node.left, target);
        } else if (target > node.value) {
            node.right = remove(node.right, target);
        } else {
            if (node.left == null) return node.right;
            if (node.right == null) return node.left;
            ReviewNode successor = minimumNode(node.right);
            node.value = successor.value;
            node.right = remove(node.right, successor.value);
        }
        return node;
    }

    private ReviewNode minimumNode(ReviewNode node) {
        while (node.left != null) node = node.left;
        return node;
    }

    List<Integer> range(int low, int high) {
        List<Integer> result = new ArrayList<>();
        if (low <= high) range(root, low, high, result);
        return result;
    }

    private void range(ReviewNode node, int low, int high,
                       List<Integer> result) {
        if (node == null) return;
        if (low < node.value) range(node.left, low, high, result);
        if (low <= node.value && node.value <= high) result.add(node.value);
        if (node.value < high) range(node.right, low, high, result);
    }

    boolean isValid() {
        return isValid(root, Long.MIN_VALUE, Long.MAX_VALUE);
    }

    private boolean isValid(ReviewNode node, long low, long high) {
        if (node == null) return true;
        if (node.value <= low || node.value >= high) return false;
        return isValid(node.left, low, node.value)
                && isValid(node.right, node.value, high);
    }

    void forceDeepViolationForTest() {
        if (root != null && root.left != null && root.left.right != null) {
            root.left.right.value = root.value + 5;
        }
    }
}

public class BstPathRangeReview {
    private static ReviewBst standardTree() {
        ReviewBst tree = new ReviewBst();
        for (int value : new int[]{50, 30, 70, 20, 40, 60, 80}) {
            tree.add(value);
        }
        return tree;
    }

    public static void main(String[] args) {
        ReviewBst tree = standardTree();
        System.out.println("path60=" + tree.searchPath(60));
        System.out.println("path65=" + tree.searchPath(65));
        System.out.println("range=" + tree.range(35, 70));
        System.out.println("invalid=" + tree.range(70, 35));
    }
}
```

執行結果：

```text
path60=[50, 70, 60]
path65=[50, 70, 60]
range=[40, 50, 60, 70]
invalid=[]
```

#### 執行重點

Range recursion 的條件同時負責正確性與剪枝，不只是最後再 filter。

### 概念 9：Systematic Debugging：症狀、Invariant 與最小案例

#### 概念說明

除錯先描述可觀察症狀，再建立最小重現資料，最後檢查 invariant。BST 常見症狀包括 inorder 不排序、remove 後少一整個 subtree、duplicate 未移除、root 沒有更新。只盯著出錯輸出，沒有檢查 tree property，通常難以定位 reference 錯誤。

#### 實際應用

- 定位 insert/delete 的方向或接線錯誤
- 將 invariant 寫成測試 oracle
- 用最小 tree 分離 leaf、one-child、two-child 問題

#### 資料變化

```text
先確認 valid=true；注入深層錯值後 valid=false；重新透過 add 建樹後 valid=true。
```

#### 設計判斷

測試程式可以刻意建立 invalid state，但 production API 不應公開任意修改 node key 的方法。

#### 範例程式

檔名：`BrokenBstRepairDemo.java`

```java
import java.util.List;

    int value;
    ReviewNode left;
    ReviewNode right;

    ReviewNode(int value) {
        this.value = value;
    }
}

            return true;

                if (current.left == null) {
                    current.left = new ReviewNode(value);
                    return true;
                }
                current = current.left;
            } else {
                if (current.right == null) {
                    current.right = new ReviewNode(value);
                    return true;
                }
                current = current.right;
            }
        }
    }

    boolean contains(int target) {
        ReviewNode current = root;
        while (current != null) {
            if (target == current.value) return true;
            current = target < current.value ? current.left : current.right;
        }
        return false;
    }

    List<Integer> searchPath(int target) {
        List<Integer> path = new ArrayList<>();
        ReviewNode current = root;
        while (current != null) {
            path.add(current.value);
            if (target == current.value) break;
            current = target < current.value ? current.left : current.right;
        }
        return path;
    }

    List<Integer> inorder() {
        List<Integer> result = new ArrayList<>();
        inorder(root, result);
        return result;
    }

    private void inorder(ReviewNode node, List<Integer> result) {
        if (node == null) return;
        inorder(node.left, result);
        result.add(node.value);
        inorder(node.right, result);
    }

    List<Integer> preorder() {
        List<Integer> result = new ArrayList<>();
        preorder(root, result);
        return result;
    }

    private void preorder(ReviewNode node, List<Integer> result) {
        if (node == null) return;
        result.add(node.value);
        preorder(node.left, result);
        preorder(node.right, result);
    }

    List<Integer> postorder() {
        List<Integer> result = new ArrayList<>();
        postorder(root, result);
        return result;
    }

    private void postorder(ReviewNode node, List<Integer> result) {
        if (node == null) return;
        postorder(node.left, result);
        postorder(node.right, result);
        result.add(node.value);
    }

    int size() {
        return size(root);
    }

    private int size(ReviewNode node) {
        if (node == null) return 0;
        return 1 + size(node.left) + size(node.right);
    }

    int height() {
        return height(root);
    }

    private int height(ReviewNode node) {
        if (node == null) return -1;
        return 1 + Math.max(height(node.left), height(node.right));
    }

    int leafCount() {
        return leafCount(root);
    }

    private int leafCount(ReviewNode node) {
        if (node == null) return 0;
        if (node.left == null && node.right == null) return 1;
        return leafCount(node.left) + leafCount(node.right);
    }

    String deleteCase(int target) {
        ReviewNode node = findNode(target);
        if (node == null) return "MISSING";
        if (node.left == null && node.right == null) return "LEAF";
        if (node.left == null || node.right == null) return "ONE_CHILD";
        return "TWO_CHILDREN";
    }

    private ReviewNode findNode(int target) {
        ReviewNode current = root;
        while (current != null) {
            if (target == current.value) return current;
            current = target < current.value ? current.left : current.right;
        }
        return null;
    }

    boolean remove(int target) {
        if (!contains(target)) return false;
        root = remove(root, target);
        return true;
    }

    private ReviewNode remove(ReviewNode node, int target) {
        if (target < node.value) {
            node.left = remove(node.left, target);
        } else if (target > node.value) {
            node.right = remove(node.right, target);
        } else {
            if (node.left == null) return node.right;
            if (node.right == null) return node.left;
            ReviewNode successor = minimumNode(node.right);
            node.value = successor.value;
            node.right = remove(node.right, successor.value);
        }
        return node;
    }

    private ReviewNode minimumNode(ReviewNode node) {
        while (node.left != null) node = node.left;
        return node;
    }

    List<Integer> range(int low, int high) {
        List<Integer> result = new ArrayList<>();
        if (low <= high) range(root, low, high, result);
        return result;
    }

    private void range(ReviewNode node, int low, int high,
                       List<Integer> result) {
        if (node == null) return;
        if (low < node.value) range(node.left, low, high, result);
        if (low <= node.value && node.value <= high) result.add(node.value);
        if (node.value < high) range(node.right, low, high, result);
    }

    boolean isValid() {
        return isValid(root, Long.MIN_VALUE, Long.MAX_VALUE);
    }

    private boolean isValid(ReviewNode node, long low, long high) {
        if (node == null) return true;
        if (node.value <= low || node.value >= high) return false;
        return isValid(node.left, low, node.value)
                && isValid(node.right, node.value, high);
    }

    void forceDeepViolationForTest() {
        if (root != null && root.left != null && root.left.right != null) {
            root.left.right.value = root.value + 5;
        }
    }
}
```

### 概念 10：綜合應用：學籍成績 BST 索引

#### 概念說明

BST node 不必只存 int。此系統以 student id 作為穩定且唯一的 key，node 保存完整 StudentRecord，完成 add、find、score update、remove 與 inorder report。修改 score 不影響排序；修改 id 則必須 remove 後重新 insert。

#### 實際應用

- 學籍、會員、商品與訂單索引
- 依 id 查詢並更新非 key 欄位
- 輸出依 key 排序的完整 object report

#### 資料變化

```text
加入 300、100、500、200；更新 id=200 的 score；刪除有兩個 child 的 id=300，以 500 作 successor。
```

#### 設計判斷

Key 應在 object 存續期間保持不變。若真正系統需要大量資料、並行與持久化，應使用資料庫索引，而不是把記憶體 BST 當成完整儲存系統。

#### 範例程式

檔名：`StudentScoreBstReviewSystem.java`

```java
import java.util.ArrayList;
import java.util.List;

class StudentRecord {
    final int id;
    final String name;
    int score;

    StudentRecord(int id, String name, int score) {
        this.id = id;
        this.name = name;
        this.score = Math.max(0, Math.min(100, score));
    }

    @Override
    public String toString() {
        return id + " " + name + " score=" + score;
    }
}

class StudentNode {
    StudentRecord data;
    StudentNode left;
    StudentNode right;

    StudentNode(StudentRecord data) {
        this.data = data;
    }
}

class StudentBst {
    private StudentNode root;

    boolean add(StudentRecord student) {
        if (student == null) return false;
        if (root == null) {
            root = new StudentNode(student);
            return true;
        }

        StudentNode current = root;
        while (true) {
            if (student.id == current.data.id) return false;
            if (student.id < current.data.id) {
                if (current.left == null) {
                    current.left = new StudentNode(student);
                    return true;
                }
                current = current.left;
            } else {
                if (current.right == null) {
                    current.right = new StudentNode(student);
                    return true;
                }
                current = current.right;
            }
        }
    }

    StudentRecord find(int id) {
        StudentNode current = root;
        while (current != null) {
            if (id == current.data.id) return current.data;
            current = id < current.data.id ? current.left : current.right;
        }
        return null;
    }

    boolean updateScore(int id, int score) {
        StudentRecord student = find(id);
        if (student == null) return false;
        student.score = Math.max(0, Math.min(100, score));
        return true;
    }

    boolean remove(int id) {
        if (find(id) == null) return false;
        root = remove(root, id);
        return true;
    }

    private StudentNode remove(StudentNode node, int id) {
        if (id < node.data.id) {
            node.left = remove(node.left, id);
        } else if (id > node.data.id) {
            node.right = remove(node.right, id);
        } else {
            if (node.left == null) return node.right;
            if (node.right == null) return node.left;
            StudentNode successor = minimumNode(node.right);
            node.data = successor.data;
            node.right = remove(node.right, successor.data.id);
        }
        return node;
    }

    private StudentNode minimumNode(StudentNode node) {
        while (node.left != null) node = node.left;
        return node;
    }

    List<StudentRecord> inorder() {
        List<StudentRecord> result = new ArrayList<>();
        inorder(root, result);
        return result;
    }

    private void inorder(StudentNode node, List<StudentRecord> result) {
        if (node == null) return;
        inorder(node.left, result);
        result.add(node.data);
        inorder(node.right, result);
    }
}

public class StudentScoreBstReviewSystem {
    public static void main(String[] args) {
        StudentBst index = new StudentBst();
        System.out.println("add=" + index.add(new StudentRecord(300, "Mina", 78)));
        System.out.println("add=" + index.add(new StudentRecord(100, "Leo", 84)));
        System.out.println("add=" + index.add(new StudentRecord(500, "Nora", 91)));
        System.out.println("add=" + index.add(new StudentRecord(200, "Ivy", 69)));
        System.out.println("duplicate="
                + index.add(new StudentRecord(100, "Other", 50)));

        System.out.println("find=" + index.find(200));
        System.out.println("update=" + index.updateScore(200, 88));
        System.out.println("remove=" + index.remove(300));
        System.out.println("missing=" + index.remove(999));

        for (StudentRecord student : index.inorder()) {
            System.out.println(student);
        }
    }
}
```

```text

add=true
add=true
add=true
duplicate=false
find=200 Ivy score=69
update=true
remove=true
missing=false
100 Leo score=84
200 Ivy score=88
500 Nora score=91
```

## 程式執行追蹤

### 追蹤一：Two-Child Root Delete

| 步驟 | Root/Subtree 狀態 | 動作 |
|---:|---|---|
| 1 | Target 50 有 left 30、right 70 | 判定 TWO_CHILDREN |
| 2 | Right subtree 為 70、60、80 | 找 minimum 60 |
| 3 | Root key 50 | 改為 60 |
| 4 | Right subtree 仍有原 node 60 | Recursive remove 60 |
| 5 | Inorder 為 20,30,40,60,70,80 | 驗證排序與 size |

### 追蹤二：Range Query [35,70]

| Current | 與範圍比較 | Recursive decision |
|---:|---|---|
| 50 | 範圍內 | 檢查兩側並收集 50 |
| 30 | 小於 low | 不走 left，只檢查 right |
| 40 | 範圍內 | 收集 40 |
| 70 | 範圍內 | 檢查 left，收集 70，不走 right |
| 60 | 範圍內 | 收集 60 |

最終 inorder result 為 `[40, 50, 60, 70]`。

## 除錯練習

### 除錯練習一：Height 的 Base Case 不一致

若 empty tree 回傳 `0`，但又希望 leaf height 為 `0`，recursive formula 會算出 leaf height 為 `1`。可採用下列其中一套一致定義：

- Empty=-1、leaf=0，以 edge 數量表示 height。
- Empty=0、leaf=1，以 node 數量表示 height。

本教材採第一套。

### 除錯練習二：Delete 後遺失 Subtree

錯誤寫法在 one-child case 一律 `return null`，會把 target 唯一的 child subtree 一起切斷。正確處理是：

```java
if (node.left == null) return node.right;
if (node.right == null) return node.left;
```

修正後至少測試 root 與 internal node 各一次。

## 常見錯誤與診斷

| 問題 | 可能原因 | 診斷方式 | 修正方向 |
|---|---|---|---|
| Recursion 無限呼叫 | Input 未接近 base case | 輸出每次參數 | 縮小 input |
| Traversal 順序錯誤 | Process node 時機錯 | 用三個 node 最小 tree | 調整 process 位置 |
| Search 找不到存在 key | Comparison direction 相反 | 輸出 search path | 小往 left、大往 right |
| Inorder 不排序 | Insert 接錯 child | 每次 add 後 validate | 修正 link assignment |
| Delete 少整個 subtree | One-child 回傳 null | 刪除只有一個 child 的 root | 回傳 non-null child |
| Two-child 出現 duplicate | 未移除原 successor | 比較 size 與 inorder | 再 remove successor |
| Root delete 無效 | 未接回 recursive result | 專門刪除 root | `root = remove(...)` |
| Validation 漏錯 | 只比較直接 child | 建立深層違規 | 傳遞 low/high |
| Range 漏端點 | 使用錯誤比較運算子 | 查詢 low=existing key | 明確 inclusive/exclusive |
| 效率突然退化 | Tree shape skewed | 輸出 height/path length | 比較平衡結構 |
